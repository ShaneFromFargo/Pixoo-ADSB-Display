
# ADSB Display
This C# application connects to a local ADS-B feeder or API to receive real-time flight data and displays the information about planes flying overhead on a Pixoo device. This project aims to provide aviation enthusiasts with a visual representation of nearby air traffic using Pixoo's pixel display capabilities.

## Features
- Connects to a local ADS-B feeder.
- Connects to [AdsbExchange via RapidAPI](https://rapidapi.com/adsbx/api/adsbexchange-com1)
- Displays real-time flight information on a Pixoo device.
- Configurable display settings including update frequency and data types displayed
